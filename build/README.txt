GithubUpdater 0.1.0
===================

Windows 上的 GitHub 软件版本跟踪与下载工具。
常驻后台抓取 Release、下载资产、校验 SHA-256 并替换文件。


快速开始
--------

1. 双击 GithubUpdater.exe

   首次启动会自动打开浏览器面板。如果没打开，看下面「面板地址」。

2. 配置 GitHub Token（强烈建议）

   右上角「设置」→「GitHub 访问令牌」。

   不配也能用，但匿名访问每小时只有 60 次配额，跟踪十几个仓库就不够了。
   配置后是 5000 次/小时。

   Token 只需 public_repo 权限。创建地址：
   https://github.com/settings/tokens

3. 「新建条目」→ 填仓库地址（如 https://github.com/jqlang/jq）
   → 选资产 → 选处理方式与目标目录 → 完成

4. 点「全部检查」看有没有新版本，然后「下载」→「应用」


面板地址
--------

端口每次启动都是随机分配的，地址记录在：

    data\runtime.json

里面的 "url" 字段就是。也可以：

  - 双击托盘图标
  - 右键托盘图标 → 打开面板
  - 右键托盘图标 → 复制地址


四类资产怎么选
--------------

  单文件替换   下载后原子替换目标文件，保留备份可回滚。
               适合 jq.exe、ripgrep.exe 这类单个可执行文件。

  压缩包解压   解压并覆盖目标目录。不会删除目录里多出的文件，
               所以你在程序目录放的配置不会丢。

  源码更新     git clone / checkout 到指定 tag。
               有未提交改动时会中止，绝不 stash/reset 你的代码。

  仅归档       按文件名模板落盘，只留最新 N 份。
               适合 APK、安装包这类"留着以后用"的文件。


便携模式
--------

所有数据都在 exe 同级的 data\ 目录：

    data\config.json    配置，可以直接编辑
    data\state.db       条目、任务、历史
    data\runtime.json   当前端口（每次启动覆盖）
    data\tmp\           原生库临时解压目录

整个目录可以随便移动。移动后开机自启的路径会在下次启动时自动修正。


开机自启
--------

设置页勾选「开机自动启动」即可，不需要管理员权限。

开机启动时带 --minimized 参数，不会弹浏览器，只在托盘待着。


关于网络
--------

如果下载超时或失败，通常是 github.com 主域不通（api.github.com 可能仍然通）。
可以在设置里启用镜像加速，预置了 ghfast.top / gh-proxy.org / gh-proxy.com。

注意：镜像本质是中间人代理，它能看到你下载了什么。
本工具会校验 SHA-256，能发现内容被篡改，但代理仍能看到流量。
默认关闭。


关闭与退出
----------

  - 关掉浏览器标签页：释放全部界面内存，后台服务照常运行
  - 右键托盘图标 → 退出：完全退出程序


系统要求
--------

Windows 10 及以上，64 位。
不需要安装 Java（已内置裁剪过的运行时）。


体积与内存
----------

  解压后磁盘占用    约 76 MB
  空载内存          约 80 MB
  跑完下载后        约 120 MB

界面在浏览器里，关掉浏览器后进程内存会明显下降。
